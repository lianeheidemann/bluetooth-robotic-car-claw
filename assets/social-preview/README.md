# Arduino Soil Moisture Monitoring

<img src="https://img.shields.io/badge/Tinkercad-FF6F00?style=for-the-badge&logo=autodesk&logoColor=white"/><img src="https://img.shields.io/badge/Arduino-00979D?style=for-the-badge&logo=arduino&logoColor=white"/>

This system reads soil moisture through a moisture sensor and displays the measurements on a 16x2 LCD. It also includes a button to enable or disable monitoring and an LED status indicator.

> Built with Arduino and simulated entirely online through
> [Tinkercad](https://www.tinkercad.com/users/4kDyp0e5KET?type=circuits).

---

## Components

- 1 Arduino UNO
- 1 soil moisture sensor
- 1 16x2 LCD
- 1 push button
- 1 LED
- Resistors
- Jumper wires
